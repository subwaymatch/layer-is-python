Everyday fixes

Small corrections that make a photo look the way it felt.

Before After

Rescue a flat photo

A hazy, overcast shot has no true blacks or whites. Curve points computed with NumPy emulate a Levels adjustment that stretches the tones to the full range; saturation and a warm overlay bring the colors back.

curve()saturation()overlay()NumPy
image = LayerImage.from_file("photos/harbor.jpg")
# Levels: map input 0.12 to black and 0.88 to white
x = np.linspace(0, 1, 26)
levels = np.clip((x - 0.12) / 0.76, 0, 1)

(image.curve("rgb", levels.tolist())
      .saturation(0.35)
      .overlay("#ffd8a8", opacity=0.25))

Food photos benefit from rich color and a touch of warmth. A gentle S-curve adds contrast without crushing the shadows.

Warm up skin tones

Per-channel curves act as a white-balance slider: raise the red midtones and lower the blue ones to warm up a cool, grey-lit portrait.

Lomo

Toy-camera look: high contrast, oversaturated color and dark corners. The vignette is a NumPy array blended with Multiply, where white in the center leaves pixels untouched.

contrast()saturation()multiply()NumPy
image = LayerImage.from_file("photos/flower-market.jpg")
h, w, _ = image.get_image_as_array().shape
y, x = np.ogrid[-1:1:h * 1j, -1:1:w * 1j]
vignette = np.clip(1.2 - 0.6 * (x**2 + y**2), 0, 1)[..., np.newaxis]

(image.contrast(1.3)
      .saturation(0.4)
      .multiply(vignette))

Creative effects

Gradients, vignettes, double exposures and false color. Most of them use NumPy arrays as blend layers.

Before After

Duotone poster

Map shadows to one color and highlights to another. A two-point curve per channel acts as a gradient map.

grayscale()contrast()curve()
image = LayerImage.from_file("photos/architecture.jpg")
shadow, highlight = (0.12, 0.08, 0.4), (1.0, 0.45, 0.42)  # indigo to coral

image.grayscale().contrast(1.2)
for channel, lo, hi in zip("rgb", shadow, highlight):
    image.curve(channel, [lo, hi])
Before After

Double exposure

Blend modes accept another photo's pixels. Screen keeps the white sky white and fills the dark silhouette with the forest; a pale green Multiply tints the result.

screen()grayscale()curve()multiply()
image = LayerImage.from_file("photos/silhouette.jpg")
forest = LayerImage.from_file("photos/forest.jpg").get_image_as_array()

(image.screen(forest)
      .grayscale()
      .curve("rgb", [0, 0.12, 0.5, 0.88, 1])
      .multiply("#cfe3dc"))
Before After

Graduated sky filter

A vertical gradient from warm tint to white, blended with Multiply, deepens the sky while leaving the lake untouched, like a graduated filter on a lens.

multiply()NumPy
image = LayerImage.from_file("photos/mountain-lake.jpg")
h, w, _ = image.get_image_as_array().shape
t = np.clip(np.linspace(0, 2.2, h), 0, 1)[:, np.newaxis, np.newaxis]
gradient = (1 - t) * np.array([0.95, 0.55, 0.4]) + t  # tint at the top fading to white

image.multiply(gradient)

Channel swap

LayerImage works on plain NumPy arrays, so anything NumPy can do is fair game. Swapping the red and green channels turns the turquoise car violet and the pink house lime.

contrast()

pixels = image.get_image_as_array()
image = LayerImage.from_array(pixels[..., [1, 0, 2]].copy())  # swap R and G

image.contrast(1.1)

One preset, many photos

Operations can also be described as data. Save a look as JSON and apply it to a whole folder with apply_from_dict() (or apply_from_json()). Here is a warm, matte preset on four different photos.

warm-matte.json
{
  "operations": [
    {"type": "curve", "channels": "rgb", "curve_points": [0.08, 0.3, 0.55, 0.78, 0.94]},
    {"type": "saturation", "factor": -0.15},
    {"type": "soft_light", "hex": "#ffb36b", "opacity": 0.65},
    {"type": "lighten", "hex": "#1e1b2e"}
  ]
}
batch.py
import json
from pathlib import Path

from layeris import LayerImage

preset = json.loads(Path("warm-matte.json").read_text())
Path("out").mkdir(exist_ok=True)
for path in Path("photos").glob("*.jpg"):
    LayerImage.from_file(path).apply_from_dict(preset).save(f"out/{path.name}")
