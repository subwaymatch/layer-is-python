Blend Modes

A blend mode combines the image (the base, A) with a blend layer (B). The layer can be a hex color, a NumPy array the same size as the image (a gradient, a texture, another photo) or anything that broadcasts to it. Every mode takes an optional opacity from 0 to 1. Below, all 14 modes blend #e8743b into the same three photos. Hover a result to see the base photo.Press and hold a result to see the base photo.

Base Photos

The unedited photos that every blend mode below is applied to.

Darken Group

The result is never lighter than the base. White is neutral.

Darken

image.darken("#e8743b") min(A, B)

Multiply

image.multiply("#e8743b") A * B

Color Burn

image.color_burn("#e8743b") 1 - (1 - A) / B

Linear Burn

image.linear_burn("#e8743b") A + B - 1

Lighten Group

The result is never darker than the base. Black is neutral.

Lighten

image.lighten("#e8743b") max(A, B)

Screen

image.screen("#e8743b") 1 - (1 - A)(1 - B)

Color Dodge

image.color_dodge("#e8743b") A / (1 - B)

Linear Dodge

image.linear_dodge("#e8743b") A + B

Contrast Group

Darken below mid-gray, lighten above it. 50% gray is neutral for most of these modes.

Overlay

image.overlay("#e8743b") 2AB if A <= 0.5, else 1 - 2(1 - A)(1 - B)

Soft Light

image.soft_light("#e8743b") Pegtop soft light

Hard Light

image.hard_light("#e8743b") 2AB if B <= 0.5, else 1 - 2(1 - A)(1 - B)

Vivid Light

image.vivid_light("#e8743b") Color burn if B <= 0.5, else color dodge

Linear Light

image.linear_light("#e8743b") A + 2B - 1

Pin Light

image.pin_light("#e8743b") Replace A depending on B

Opacity

Opacity mixes the blended result back with the original: overlay("#ff4f8b", opacity=...) on the palace-pond photo.

Choosing a Blend Color

The same mode gives very different moods depending on the color: soft_light(color) on the hanbok-portrait photo.

Blending with Arrays

Pass a NumPy array instead of a hex string to blend per pixel. The creative effects examples use this for a vignette, a graduated filter and a double exposure.

h, w, _ = image.get_image_as_array().shape
t = np.linspace(0, 1, h)[:, np.newaxis, np.newaxis]  # 0 at the top, 1 at the bottom
gradient = (1 - t) * np.array([1.0, 0.6, 0.3]) + t    # orange fading to white

image.multiply(gradient)  # white is neutral for multiply
